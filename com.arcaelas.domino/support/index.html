Soporte — Dominó Venezolano

¿Necesitas ayuda con Dominó Venezolano? Escríbenos a arcaela.reyes@gmail.com. Cuéntanos qué ocurrió, el modelo de tu teléfono y la versión de su sistema, y te respondemos por correo.

Preguntas frecuentes

¿Cómo se juega?

La mesa siempre tiene cuatro puestos en dos parejas, y la computadora ocupa los puestos que no tienen persona. Puedes jugar solo contra la computadora o en red local con 2 o 4 personas. Las reglas son las del dominó venezolano, y el manual del juego las explica con jugadas animadas.

¿Cómo creo una mesa en red?

Toca crear partida, elige en cada puesto si lo ocupa una persona o la computadora y define cuánto vale la partida. El juego genera un código QR y un código corto por cada puesto de persona: cada amigo escanea el suyo o lo escribe a mano.

No puedo unirme a una mesa

  • Todos los teléfonos deben estar conectados a la misma red wifi.
  • Cada invitación es de un solo uso y vale para un puesto. Si ya se usó, pide al anfitrión una nueva.
  • En iPhone, permite el acceso a la red local: Ajustes > Privacidad y seguridad > Red local > Dominó Venezolano.
  • Algunas VPN y algunas redes públicas o de invitados impiden que los teléfonos se vean entre sí. Prueba apagando la VPN o con otra red.

La cámara no lee el código QR

Permite el acceso a la cámara en los ajustes del sistema, o escribe el código a mano. La cámara no es obligatoria.

Se cortó la conexión en medio de la partida

Vuelve a abrir el juego: la mesa te espera y vuelves a entrar con tu invitación guardada. El anfitrión debe dejar el juego abierto y con la pantalla encendida, porque su teléfono es el que sostiene la mesa.

¿Qué es una cabra?

Una piedra mal puesta, que no casa con la punta. Como en una mesa real, el juego te deja ponerla. Se marca sutilmente para todos, y solo quien la puso puede retirarla antes de que se juegue la siguiente piedra.

¿Por qué no se resaltan las piedras que puedo jugar?

Porque el juego se comporta como una mesa de verdad: respetar las normas queda de parte de los jugadores.

¿Hace falta internet?

No. Contra la computadora se juega sin conexión, y en red solo hace falta una wifi compartida.

Support — Dominó Venezolano

Need help with Dominó Venezolano? Write to us at arcaela.reyes@gmail.com. Tell us what happened, your phone model and its system version, and we'll reply by email.

Frequently asked questions

How do I play?

The table always has four seats in two pairs, and the computer takes any seat without a person. You can play alone against the computer or over the local network with 2 or 4 people. The rules are those of Venezuelan dominoes, and the in-game manual explains them with animated plays.

How do I create a network table?

Tap create game, choose for each seat whether a person or the computer takes it and set how much the game is worth. The game generates a QR code and a short code for each human seat: each friend scans theirs or types it by hand.

I can't join a table

  • All phones must be connected to the same Wi-Fi network.
  • Each invitation is single-use and valid for one seat. If it was already used, ask the host for a new one.
  • On iPhone, allow local network access: Settings > Privacy & Security > Local Network > Dominó Venezolano.
  • Some VPNs and some public or guest networks prevent phones from seeing each other. Try turning off the VPN or using another network.

The camera won't read the QR code

Allow camera access in the system settings, or type the code by hand. The camera is not required.

The connection dropped in the middle of the game

Open the game again: the table waits for you and you get back in with your saved invitation. The host must keep the game open with the screen on, because their phone holds the table.

What is a "cabra"?

A misplaced tile that doesn't match the end. As at a real table, the game lets you play it. It is subtly marked for everyone, and only the player who placed it can take it back before the next tile is played.

Why aren't playable tiles highlighted?

Because the game behaves like a real table: following the rules is up to the players.

Do I need internet?

No. Against the computer you play offline, and over the network you only need a shared Wi-Fi.
