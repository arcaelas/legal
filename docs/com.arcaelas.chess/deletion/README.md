# Eliminación de datos — ChessAI

Última actualización: 23 de octubre de 2026.

> ChessAI no tiene cuentas ni servidores: tus partidas, estadísticas y ajustes viven solo en tu dispositivo. Nosotros no guardamos datos tuyos que podamos borrar.

## Borrar tus datos

- **Desde la app:** Configuración → Datos → Eliminar todos los datos → Eliminar todo.
- **Android:** Ajustes → Apps → ChessAI → Almacenamiento → Borrar almacenamiento, o desinstala la app.
- **iPhone:** mantén pulsado el ícono de ChessAI → Eliminar app.

Se borran todas las partidas guardadas, las estadísticas y las preferencias (tema, idioma, dificultad y opciones del tablero). Esta acción no se puede deshacer.

Si tu sistema hace copias de seguridad automáticas (Google o iCloud), esas copias se gestionan desde la configuración de la cuenta de tu dispositivo.

# Data deletion — ChessAI

Last updated: October 23, 2026.

> ChessAI has no accounts and no servers: your games, statistics and settings live only on your device. We keep no data of yours that we could delete.

## Delete your data

- **From the app:** Settings → Data → Delete all data → Delete all.
- **Android:** Settings → Apps → ChessAI → Storage → Clear storage, or uninstall the app.
- **iPhone:** long-press the ChessAI icon → Remove App.

This erases all saved games, the statistics and the preferences (theme, language, difficulty and board options). This action cannot be undone.

If your system makes automatic backups (Google or iCloud), those backups are managed from your device account settings.
